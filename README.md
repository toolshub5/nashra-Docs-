# Nashra Docs | نشرة - قارئ وإدارة المستندات الاحترافي

**Nashra Docs (نشرة)** هو تطبيق قارئ وإدارة مستندات أصلي واحترافي تم بناؤه بنظام Android Native (Kotlin & Jetpack Compose)، مع دعم معماري كامل للغات والتصميم الثنائي (العربية RTL والإنجليزية LTR).

---

## الميزات الرئيسية (Core Features)

1. **دعم شامل لصيغ الملفات**:
   - **PDF**: عارض أصلي سريع وسلس عبر `PdfRenderer` مع تكبير وتصغير وتصفح دقيق للصفحات ومؤشرات رقمية.
   - **Microsoft Word (DOCX)**: قراءة متقدمة للفقرات، العناوين، الجداول، والتنسيقات دون مكتبات خارجية ثقيلة.
   - **Microsoft Excel (XLSX) & CSV**: جداول بيانات تفاعلية مع رؤوس أعمدة وتمرير أفقي وعمودي سلس.
   - **Microsoft PowerPoint (PPTX)**: عارض شرائح متقدم للتنقل السلس بين الشرائح ومراجعة العروض التقديمية.
   - **الصور (Images)**: دعم JPG, PNG, WEBP بدقة كاملة وتكبير بلمس الشاشة.
   - **المستندات النصية (TXT)**: محرر وقارئ نصوص قابل لتعديل حجم الخط وألوان القراءة (فاتح، داكن، سيبيا).

2. **الهوية البصرية وتجربة المستخدم**:
   - واجهة عصرية هادئة تعتمد اللون الأخضر الزمردي والتركوازي (`#0F766E`, `#2DD4BF`).
   - بطاقات ناعمة ذات حواف مستديرة وتدرجات ضوئية مريحة للعين.
   - دعم كامل للوضع الداكن (Dark Mode) ووضع القراءة السيبيا (Sepia Eye-Protection Mode).
   - واجهة عربية افتراضية مع دعم كامل للاتجاه من اليمين لليسار (RTL) وتبديل فوري للغة الإنجليزية (LTR).

3. **أدوات المستندات الاحترافية (Tools)**:
   - **دمج ملفات PDF (Merge PDFs)**: دمج مستندات متعددة في ملف واحد متكامل.
   - **تحويل الصور إلى PDF (Images to PDF)**: تجميع الصور في وثيقة PDF عالية الجودة.
   - **تحويل النصوص إلى PDF (Text to PDF)**: تحويل النصوص والمقالات المكتوبة إلى PDF جاهز للطباعة.
   - **ضغط PDF (Compress PDF)**: تحسين حجم الملفات بكفاءة للحفظ والمشاركة.
   - **تدوير الصفحات (Rotate PDF)**: تدوير صفحات المستندات وحفظها.

4. **التعرف الضوئي على الحروف (OCR)**:
   - استخراج فوري للنصوص من الصور والمستندات المصورة بكاميرا الهاتف أو من المعرض.
   - دعم كامل للغة العربية والإنجليزية، مع إمكانية نسخ النص، حفظه كمستند جديد، أو تصديره.

5. **التوقيع الرقمي المحلي والتظليل (Signatures & Annotations)**:
   - رسم التوقيع بالإصبع بدقة وسلاسة أو كتابة توقيع نصي مخصص.
   - تثبيت التوقيع وحفظه محلياً على صفحات المستند.
   - أداة تظليل بألوان متعددة (أصفر، أخضر، أزرق، وردي) مع إضافة ملاحظات نصية.
   - تصدير نسخة موقعة ومظللة بصيغة PDF جديدة مع التعديلات.

6. **إدارة الملفات وقاعدة البيانات المحلية (Local Storage & Room)**:
   - حفظ كامل لسجل القراءة، الصفحة الأخيرة، المفضلة، ونسبة الإنجاز باستخدام Room Database.
   - استقبال ومشاركة الملفات مباشرة عبر Android Intents (`ACTION_VIEW`, `ACTION_SEND`) من واتساب والبريد والتطبيقات الخارجية.
   - خصوصية 100% دون رفع تلقائي للملفات إلى أي خوادم خارجية.

## هيكل المشروع المعماري (Architecture)

```
com.example/
├── MainActivity.kt               # نقطة الدخول، معالجة Intents، والواجهة الرئيسية
├── data/
│   ├── model/                   # كيانات البيانات (Document, Highlight, Signature, OCR, Settings)
│   └── local/                   # Room Database, DAO, Repository, PreferencesManager
├── engine/
│   ├── DocumentParser.kt        # معالجات قراءة DOCX, XLSX, PPTX, CSV, TXT, Images
│   ├── PdfRendererHelper.kt     # محرك تصيير صفحات PDF والذاكرة المؤقتة (LRU Cache)
│   ├── PdfToolsEngine.kt        # أدوات الدمج، التحويل، الضغط، وتصدير التوقيعات
│   └── OcrEngine.kt             # محرك استخراج النصوص ثنائي اللغة
├── ui/
│   ├── components/              # مكونات البطاقات، أشرطة التنقل، التوقيع، التظليل، والاستيراد
│   ├── locale/                  # قواميس وموارد النصوص العربية والإنجليزية
│   ├── navigation/              # مسارات الشاشات (Home, Library, Reader, Tools, Settings)
│   ├── screens/                 # واجهات التطبيق الرئيسية
│   └── theme/                   # لوحة ألوان الزمرد والتركواز والأنماط البصرية
```

## استخراج وتثبيت حزم التطبيق (Exporting APK & AAB)

1. من قائمة الإعدادات (Settings) في استوديو الذكاء الاصطناعي:
   - اختر **Download Project ZIP** للحصول على الكود المصدري كاملاً.
   - أو اضغط **Export / Generate APK** للحصول على ملف التثبيت المباشر `nashra_docs.apk`.
   - أو اضغط **Generate Android App Bundle (AAB)** لنشر التطبيق في متجر Google Play.

2. لبناء الحزم محلياً عبر سطر الأوامر:
   ```bash
   # بناء حزمة تصحيح الأخطاء APK
   gradle :app:assembleDebug

   # بناء حزمة النشر Google Play AAB
   gradle :app:bundleRelease
   ```
